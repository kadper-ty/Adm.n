# مكتبة التقنية الغذائية (Android)

تطبيق أندرويد يعمل بدون إنترنت (ما عدا فتح الروابط)، يحتوي على:

- **المكتبة**: فهرس مراجع أجنبية، مع مصادر مفتوحة ومستودعات عربية وأجنبية، وأزرار بحث مباشر، وإمكانية إضافة مراجعك الخاصة.
- **المصانع**: دليل إنشاء مصنع من الألف إلى الياء (سردين، لبن/زبادي، جبنة بيضاء، معجون بندورة، زيت زيتون).
- **المعرفة**: تحاليل المخبر، المواد والمضافات، عمليات التصنيع، الجودة والسلامة.
- **بحث** شامل داخل كل المحتوى، و**محفوظاتي** (المفضلة + مراجعك).

## بناء الـ APK على GitHub

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **كل محتويات** هذا المجلد (بما فيه المجلد المخفي `.github`) إلى المستودع.
   - الأسهل من الكمبيوتر: Add file ← Upload files ← اسحب المجلدات وأفلتها.
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (أو شغّل `Build Android APK` يدوياً).
4. بعد 5–10 دقائق افتح التشغيل الناجح ← قسم **Artifacts** ← نزّل `FoodTechLibrary-apk` ← فك الضغط ← ثبّت `FoodTechLibrary.apk`.

لنشر رابط تحميل دائم: أنشئ **Release** باسم tag مثل `v1.0` وسيُرفق الـ APK تلقائياً.

> الـ APK الناتج هو نسخة debug موقّعة بمفتاح تجريبي، تصلح للتثبيت المباشر. للنشر على Google Play تحتاج توقيع release.

## تعديل المحتوى

كل المحتوى ملفات نصية في `www/js/data/`:

- `library.js`: المراجع والمصادر.
- `plants.js`: المصانع (انسخ كتلة مصنع موجود وعدّلها لإضافة مصنع جديد).
- `knowledge.js`: التحاليل والمواد والعمليات.

## ملاحظات مهمة

- التطبيق لا يضم كتباً محمية بحقوق النشر؛ يضم فهرساً ببياناتها وروابط بحث قانونية. أضف مراجعك العربية من تبويب «محفوظاتي».
- الأرقام والتكاليف تقديرية للتخطيط الأولي، وتحتاج عروض أسعار فعلية ودراسة جدوى قبل أي استثمار.
